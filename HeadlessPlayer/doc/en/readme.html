Overview: Headless Media Player is a high-performance, completely headless, privacy-oriented background media player add-on for the NVDA screen reader. It allows you to play local audio/video files, entire directories, playlists, and online streams (YouTube videos, playlists, channels, search queries, live streams, Twitch, SoundCloud, web radio) with zero visible UI, zero floating windows, and zero taskbar presence.

1. Core Concept: Modal Keyboard Capture (Player Mode)

Traditional media players require switching windows, stealing focus from your active document, web browser, or chat. Headless Media Player operates entirely in the background.

When you enter Player Mode (by pressing NVDA+Ctrl+Shift+P):

  • All keystrokes are intercepted exclusively by the media engine and are blocked from leaking into background applications.
  • Pressing single letters (e.g. Space to pause, arrows to seek, u to search YouTube, Tab to jump tracks) controls the player instantly without typing characters into open documents.
  • Subtle acoustic tones and NVDA speech announcements confirm entering and exiting Player Mode.
  • Pressing Escape or NVDA+Ctrl+Shift+P exits Player Mode immediately and restores standard keyboard input.

2. Quick Start Guide

  1. Play any file or folder from Explorer: Focus on any media file or folder in Windows Explorer or Desktop and press NVDA+Ctrl+Windows+E. Playback starts immediately in the background and activates Player Mode!
  2. Open File Dialog: In Player Mode, press o to browse for a media file, or f to queue an entire folder.
  3. Search YouTube: In Player Mode, press u, type your search query (in Arabic or English, e.g. Surah Al-Kahf or Audiobook Chapter 1), and press Enter. Browse results with Up/Down arrows and press Enter to play!
  4. Control Playback: Press Space to pause/resume, Left/Right to seek, Up/Down for volume, i for track details, and Escape when you want to return to typing in other applications.

4. Complete Player Mode Shortcuts Reference

The following commands are available while Player Mode is active:

4.1. Playback & Volume Controls

Key Action Description
Space Play / Pause Toggles playback state. If the track reached the end, restarts from the beginning.
s Stop Stops playback, saves resume position, and rewinds to 0:00.
m Mute / Unmute Toggles audio mute state.
Up Arrow Volume Up Increases volume by 5% (announced by NVDA).
Down Arrow Volume Down Decreases volume by 5% (announced by NVDA).
b Bass Boost Increases bass equalizer by +3 dB.
Shift + b Bass Reduce Decreases bass equalizer by -3 dB.
Escape Exit Player Mode Deactivates Player Mode and restores normal keyboard input immediately.
Control Silence Speech Instantly cancels ongoing speech announcements.

4.2. Granular Seeking & Direct Position Jumps

Key Action Default Step
Left Arrow / Right Arrow Normal Seek - / + 5 seconds (Configurable in Settings)
Alt + Left Arrow / Alt + Right Arrow Slow / Precise Seek - / + 1 second (Configurable in Settings)
Ctrl + Left Arrow / Ctrl + Right Arrow Fast Seek - / + 30 seconds (Configurable in Settings)
Shift + Left Arrow / Shift + Right Arrow Ultrafast Seek - / + 5 minutes (300s, Configurable)
1 to 9 (top row or numpad) Percentage Jump Jumps directly to 10%, 20%, 30%, ... 90% of file duration.
0 Jump to Start Rewinds directly to 0% (beginning of file).

4.3. Pitch-Preserved Variable Speed

Key Action Description
Ctrl + Up Arrow Fine Speed Up Increases speed by +0.1x (audio pitch remains 100% natural and clear).
Ctrl + Down Arrow Fine Speed Down Decreases speed by -0.1x.
Shift + Up Arrow Next Preset Speed Cycles up through presets: 1.0x → 1.25x → 1.5x → 1.75x → 2.0x → 2.25x → 2.5x → 3.0x → 3.5x → 4.0x.
Shift + Down Arrow Previous Preset Speed Cycles down through standard speed presets.

4.4. A-B Segment Looping & Repeat Modes

Key Action Description
[ (or Arabic ج) Mark Point A Sets loop starting timestamp at current position.
] (or Arabic د) Mark Point B Sets loop ending timestamp and immediately starts endless repetition between Point A and Point B.
c Clear A-B Loop Clears A-B loop points and returns to normal sequential playback.
r Toggle Repeat Mode Cycles repeat mode: Track Repeat (repeat single file) → Playlist Repeat (repeat entire queue) → Repeat Off.

4.5. Playlist, Files, and Chapter Navigation

Key Action Description
Page Down (or Tab) Next Track Skips to the next track in the playlist queue.
Page Up (or Shift + Tab) Previous Track Skips to the previous track in the playlist queue.
n Toggle Auto-Next Enables or disables automatic playback of the next track when current track finishes.
z Toggle Shuffle Shuffles playlist order non-destructively. Toggle off to restore original order.
Ctrl + Shift + Right Arrow Next Chapter Jumps to next chapter (announces chapter title/number).
Ctrl + Shift + Left Arrow Previous Chapter Jumps to previous chapter.
a Cycle Audio Track Switches between alternative audio streams or languages in multi-audio video files.
o Open File Dialog Opens native file selection dialog to play audio or video.
f Open Folder Dialog Opens native folder picker to queue all media files in natural alphabetical order.
e Play Explorer Selection Plays the focused or selected file/folder in Windows Explorer.

4.6. Speech Queries & Help

Key Action Description
i Speak Media Info Announces track title, total formatted duration, and playlist index (e.g. "Track 3 of 15").
Ctrl + i Speak Remaining Time Announces remaining playback time in hours, minutes, and seconds.
Shift + i Speak Elapsed Time Announces elapsed playback time.
h (or Arabic ا) Show Shortcuts Help Opens an accessible quick reference dialog displaying all shortcuts.

5. YouTube & Online Web Streaming

Headless Media Player includes a built-in stream extraction engine powered by embedded yt-dlp and lightweight JavaScript engine support. It requires zero external installations.

5.1. Searching YouTube (u Key)

  1. Press u while in Player Mode.
  2. A dialog appears asking for a URL or search query. (If a web link is currently copied to your clipboard, it is automatically pasted for you!)
  3. Type any text search query (e.g. سورة الرحمن العفاسي or BBC World News live) and press Enter.
  4. An accessible results browser appears displaying real matching videos, playlists, and channels with titles, uploaders, and durations.
  5. To play a video: Move with Up/Down arrows and press Enter. Playback starts headlessly in seconds!
  6. To explore a Playlist or Channel: Press Enter on any Playlist or Channel result to drill-down and view its individual tracks.
  7. To queue an entire Playlist at once: Focus on a Playlist item, press Tab to reach the Play Entire Playlist button, and press Space or Enter.
  8. Press Backspace to go back one level, or Escape to close the browser.

5.2. Direct URL Playback (u Key)

Paste any supported online URL into the u dialog and press Enter:

  • Single YouTube Video / Short / Live: https://www.youtube.com/watch?v=... or https://youtu.be/...
  • YouTube Playlist: https://www.youtube.com/playlist?list=... (Queues all tracks automatically with Auto-Next support!)
  • Arbitrary Media Streams: Twitch streams, SoundCloud tracks, direct HTTP/HTTPS audio links, .m3u8 HLS live streams, and online radio stations.

5.3. YouTube Account, Subscriptions & Trending (p Key)

Press p in Player Mode to open the YouTube Portal. You can browse:

  • Regional Trending: Choose your country (Egypt, Saudi Arabia, UAE, USA, UK, Germany, France, Japan, etc.) and explore trending videos.
  • My Subscriptions & My Playlists: Browse your personal YouTube feed and private playlists (see Cookies Setup below).

5.4. Copy Stream Link (v Key)

Pressing v during playback copies the direct web link or source file path of the currently playing track to the Windows Clipboard and speaks a confirmation message.

6. Important: YouTube Login & Cookies Setup

Why direct Chrome cookie extraction does not work:

Modern versions of Google Chrome and Microsoft Edge on Windows (Chrome 120+) enforce strict App-Bound Encryption (DPAPI + v20 key protection). This prevents any external application from reading Chrome's cookie database directly from the disk. Attempting direct Chrome extraction will fail or produce authentication errors.

How to export cookies easily using a Browser Extension:

  1. Install a trusted cookie export extension in your browser:
    • For Google Chrome, Brave, Edge: Install Get cookies.txt LOCALLY (Chrome Web Store)
    • For Mozilla Firefox: Install cookies.txt (Firefox Add-ons)
  2. Open YouTube.com in your browser and make sure you are logged into your Google account.
  3. Click the extension icon in your browser toolbar and click Export (or download) to save your cookies.txt file to your computer (e.g. into your Documents or Downloads folder).
  4. In NVDA, open NVDA Menu → Preferences → Settings → Headless Media Player.
  5. Under YouTube Stream Settings, click Browse... next to Custom Cookies File, select your exported cookies.txt file, and click OK.

Now Headless Media Player can access all your private playlists, liked videos, subscriptions, and age-restricted content seamlessly without errors!

7. Windows Explorer & Desktop Integration

You can start playback instantly from Windows Explorer or your Desktop without opening any dialogs:

  • Select or focus on any audio or video file (or folder containing media files) in Windows Explorer or Desktop.
  • Press NVDA+Ctrl+Windows+E (globally) or e (in Player Mode).
  • The add-on automatically detects the focused item (even if file extensions are hidden in Windows), builds an ordered playlist, begins playback, and enters Player Mode immediately!

8. NVDA Settings & Customization

Open NVDA Menu → Preferences → Settings → Headless Media Player to customize:

8.1. Speech Feedback & Verbosity

  • Toggle individual voice announcements for: volume changes, seek time announcements, speed adjustments, track changes, repeat mode toggles, and A-B loop point markers.

8.2. Configurable Seek Jump Sizes

  • Customize the number of seconds for: Normal Seek (default: 5s), Slow Seek (default: 1s), Fast Seek (default: 30s), and Ultrafast Seek (default: 300s).

8.3. Playback Defaults & Resume Position

  • Automatic Resume: Automatically saves and restores playback position for long lectures, podcasts, and audiobooks.
  • Default Speed & Auto-Next: Set default playback speed and whether playlists advance automatically.
  • Auto-Enter Player Mode: Automatically activates Player Mode whenever new media is loaded.

8.4. YouTube Stream Settings & Updates

  • Audio Stream Quality: Choose preferred stream format: Opus (High Quality), M4A / AAC, or Best Available.
  • Custom Cookies File: Select your exported cookies.txt file for full account synchronization.
  • Check for Updates Button: Checks GitHub for the latest stream extractor updates and updates the bundled streaming engine in the background.

8.5. Interactive Keyboard Shortcuts Customizer

Click the Customize Shortcuts button in settings to open an interactive dialog where you can assign multi-key combinations (such as Shift + Tab, Ctrl + Space, or custom letters) to any player action with live key-press capture and searchable suggestions.

10. Tips & Troubleshooting

  • Can't type into other programs? You are currently in Player Mode. Press Escape or NVDA+Ctrl+Shift+P to exit Player Mode and resume normal typing.
  • Rapid Seeking: Holding down seek keys will debounce speech announcements and announce the final destination time cleanly when you release the key.
  • Silence Speech: Tap bare Control at any time in Player Mode to immediately silence speech without interrupting audio playback.
